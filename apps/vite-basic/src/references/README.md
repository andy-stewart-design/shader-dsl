# Reference shader translations

These ports preserve the reference GLSL arithmetic and matrix constructor coefficients. The GLSL references use bottom-left `gl_FragCoord`; Shdr uses top-left `coord`, so each port reconstructs bottom-left pixel coordinates where needed. `u_time`, `u_resolution`, and `u_mouse` are automatic inputs. The browser parity check is `packages/runtime/test/verify-references.mjs`; it compares full frames from a defined GLSL baseline, generated WebGL, and presented WebGPU. It covers ten scenarios: square and non-square sizes `48×48`, `53×41`, `59×35`, `61×37`, `62×34`, `63×37`, and `67×39`, pinned times `0`, `1.35`, `2.2`, `2.4`, `2.75`, and `4.0`, varied nonzero top-left mouse positions, and custom-uniform overrides for scream-wave and ben-day-spotlight. The `scream-wave` `t=4.0`, intensity `0.92` case is the high-emotion coverage.

- [`horizon-burn.frag`](horizon-burn.frag) → [`horizon-burn.shdr.ts`](horizon-burn.shdr.ts): local `palette` and `filmGrain` helpers. Grain is evaluated from reconstructed bottom-left coordinates. `u_mouse` and the unused `shdr_uv` declaration have no effect. `verify-horizon-burn.mjs` compares the original, generated WebGL, and presented WebGPU; grain precision is not promised bit-identical across GPUs.
- [`plasma.frag`](plasma.frag) → [`plasma.shdr.ts`](plasma.shdr.ts): local `filmGrain` helper and reconstructed bottom-left coordinates. The original host did not specify custom values, so `scale=8`, `speed=1`, `complexity=1.5`, `grain=0.025`, `colorA=(0.08,0.1,1)`, and `colorB=(1,0,1)` are illustrative defaults. `verify-plasma.mjs` also checks host overrides.
- [`ben-day-spotlight.frag`](ben-day-spotlight.frag) → [`ben-day-spotlight.shdr.ts`](ben-day-spotlight.shdr.ts): `dpi=8`, `spread=0.32`, and `blur=0.08` are deterministic illustrative host defaults. The parity suite includes these defaults.
- [`circles-circling.frag`](circles-circling.frag) → [`circles-circling.shdr.ts`](circles-circling.shdr.ts): ports the circle, hue, and satellite placement helpers, retaining the reference `mat2` coefficients. The reversed hue `smoothstep(2,1,x)` is written as `1-smoothstep(1,2,x)` for defined cross-target behavior.
- [`infinite-squircle.frag`](infinite-squircle.frag) → [`infinite-squircle.shdr.ts`](infinite-squircle.shdr.ts): retains the unusual cosine-based matrix coefficients exactly. It has no custom host values.
- [`moby-gradient.frag`](moby-gradient.frag) → [`moby-gradient.shdr.ts`](moby-gradient.shdr.ts): ports hash/noise, rotation, grain, and vignette helpers. Its reversed layer blend smoothstep is normalized to an equivalent defined interval.
- [`scream-wave.frag`](scream-wave.frag) → [`scream-wave.shdr.ts`](scream-wave.shdr.ts): ports the emotion, noise, waveform, glow, reflection, and grading paths. Since the reference host did not specify them, `intensity=1` and `waveSpeed=1` are documented deterministic defaults. Its reversed core smoothsteps are normalized to `1-smoothstep(0,thickness,distance)`.

The parity test normalizes only those reversed smoothsteps in its GLSL baseline because GLSL leaves reversed `smoothstep` intervals undefined, and asserts every expected replacement count. It reports mean, p95, p99, and maximum absolute RGB error per pixel (the three channel errors are averaged, in 8-bit units); alpha must be finite for every frame and presented WebGPU alpha must be opaque. All scenarios use the default limits of mean/p95/p99/max `0.5/1/2/4`; repeated pinned Chromium/SwiftShader runs measured zero error for both generated targets. These are not a cross-GPU bit-identity promise.
