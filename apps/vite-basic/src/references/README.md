# Reference shader translations

- [`horizon-burn.frag`](horizon-burn.frag) → [`horizon-burn.shdr.ts`](horizon-burn.shdr.ts): an algebraic Shdr translation with `palette` and both `filmGrain` calls inlined. Paste the `.shdr.ts` source into the REPL to see WebGL and WebGPU previews. `u_time` and `u_resolution` are automatic inputs; `u_mouse` and the unused `shdr_uv` declaration in the GLSL have no effect. Shdr's top-left `coord` is explicitly converted back to the reference's bottom-left `gl_FragCoord` before calculating UVs and grain. The browser test in `packages/runtime/test/verify-horizon-burn.mjs` compares the original GLSL's pixels against generated WebGL pixels **and presented WebGPU pixels** at pinned resolution and time in Chromium/SwiftShader. Large `sin`/`fract` products make exact grain pixels sensitive to hardware precision; this test is not a cross-GPU bit-identity promise.
- [`ben-day-spotlight.frag`](ben-day-spotlight.frag) → [`ben-day-spotlight.shdr.ts`](ben-day-spotlight.shdr.ts): hand-authored translation with illustrative `dpi`/`spread`/`blur` defaults; reproduce a particular reference frame by pinning its actual host values.
