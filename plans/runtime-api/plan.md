# Implement the browser runtime API

Status: proposed implementation plan; review each gate before widening scope. The agreed [v1 contract](./spec.md) is authoritative. This plan delivers workspace-local browser APIs for the **existing fragment shader subset**, not npm distribution, custom uniforms, textures, native runtimes or transparent canvas output. Preserve the user's other in-progress plans and changes; do not silently omit them from a later PR.

## Starting point and invariants

- [`@shdr/core`](../../packages/core/src/index.ts) exposes `lowerFragment` and target-specific `generateFragment`/`compileFragment`. [`@shdr/vite`](../../packages/vite/src/index.ts) currently emits a **GLSL string** for a default `.shdr.ts` import; [`shdr`](../../packages/shdr/src/types.ts) types `createFragmentShader` as returning a branded string. Both are intentionally breaking in this plan. TypeScript 7 editor/core shader semantics and original-source diagnostics must remain unchanged.
- [`apps/repl/src/App.tsx`](../../apps/repl/src/App.tsx) lowers once and drives two separate REPL-local renderers. Its [WebGL](../../apps/repl/src/webgl-renderer.ts) and [WebGPU](../../apps/repl/src/webgpu-renderer.ts) implementations prove canvas/pipeline/pixel parity but expose no host-facing contract. WebGPU currently discovers bindings from generated WGSL text; the public runtime must use artifact metadata instead.
- [`apps/vite-basic/src/main.ts`](../../apps/vite-basic/src/main.ts) expects a GLSL string and directly manages WebGL. Its build/dev/render verification scripts, Vite plugin tests, `shdr` types and REPL tests all need updating, not a second compatibility import mode. The Vite compiler runs at build time; **static consumers must not ship `@shdr/core` or Babel Parser**. Browser-side compilation is explicit and opt-in.
- `coord` and `mouse` are top-left physical pixels. GLSL's `coord` use implicitly binds resolution; WGSL does not. Only referenced uniforms are bound; WGSL's existing group 0 binding indices are fixed. The renderer owns an **opaque** canvas and keeps the previous shader after a failed replacement when the surface is valid. No auto-fallback between backends.

## Gate 0 — freeze the small public surface

Before extraction, record exact exported names, type-only dependencies, import paths, and error/result types in typed compile-only examples for **both** producers and renderers. The illustrative `@shdr/runtime/webgl` and `/webgpu` subpaths in the spec are a candidate, not an already shipped package. Choose one artifact type shared by the DSL return type, core compiler, Vite output and runtime inputs; avoid a runtime import of compiler values through that type. Avoid a root runtime barrel that imports both GPU backends.

Define the observable operations: creation draws once then starts animation unless `{ animate: false }`; `draw()` submits one frame and refreshes default uniforms; `setShader(artifact)` atomically installs a newer candidate, or leaves the last valid one on failure; `dispose()` is idempotent. Specify an explicit **superseded** result (neither success nor backend failure) for overlapping asynchronous shader installs. Initial/replacement failures are returned or rejected to the caller; later RAF/device/context failures have one explicit notification path and do not escape as uncaught browser errors. Distinguish adapter/device unavailable, generated-module/pipeline/draw errors and terminal loss; never relabel a backend error as an original-source Shdr diagnostic. Whether WebGL creation is synchronous or awaitable can be selected for the smallest consistent API, but the typed examples must settle it before implementation.

Freeze default input behavior: draw buffer tracks CSS size × DPR; pointer listeners on each canvas start at `(0, 0)`, use +Y down and retain their last position on leave; elapsed time starts at successful shader install and advances on draws. `animate: false` does **not** create an RAF loop (including on pointer move or resize), but creation/replacement still draws once and manual `draw()` observes the latest size, mouse and clock. Decide the minimal **opt-in** mouse/clock coordination hook needed by the two-canvas REPL, without requiring ordinary hosts to supply defaults or introducing a general custom-uniform API. Treat a lost device/context as terminal: report it, stop and require explicit disposal/recreation. This gate fixes behavior, not a reusable native/offscreen pipeline interface.

**Gate 0 acceptance:** typed API sketches cover a static Vite import, an opt-in browser compilation result, both backend constructors, animate on/off, replacement, error handling and disposal. Resolve any incompatible return-type or initial-draw assumptions now rather than during REPL migration.

## Phase 1 — one artifact from both compiler paths

1. Add a compiler operation that lowers source **once**, produces GLSL ES 3.00 and WGSL from the same unchanged target-neutral IR, and returns either a serializable dual-target artifact or the existing original-source diagnostics. Keep existing `compileFragment(source, { target })` if used elsewhere; do not duplicate semantic validation or perform two independent lowerings. Do not execute authored `.shdr.ts` as JavaScript.
2. Derive `defaults.glsl` and `defaults.wgsl` from IR expression dependencies (including GLSL's implicit `coord` → resolution dependency), not emitted-source regexes. Use deterministic ordering and stable WGSL bindings 0/1/2. Validate no/some/all subsets, including `coord` without an explicit resolution reference. Frozen IR tests must prove this metadata did not introduce GLSL/WGSL syntax into the IR.
3. Change [`shdr`](../../packages/shdr/src/dsl.ts)'s authored-module result/public type from a branded GLSL string to the artifact shape. Update its public type tests, Vite-generated module typing and TypeScript 7 editor/fixture checks; the runtime stub still throws if the authored source is executed without a transform. The exact artifact name/branding is settled in Gate 0. Do not create a legacy string-returning alias solely to retain this alpha API.
4. Make the default Vite `.shdr.ts` transform emit the artifact as literal module data, without runtime `@shdr/core`, DSL stubs or Babel Parser imports. Retain source-located Vite errors. Provide a separately importable browser compiler operation that returns the **same** artifact/result shape; the REPL can load it normally or lazily, but static consumers must not acquire it transitively.

**Gate 1 acceptance:** core tests cover diagnostic ranges, deterministic outputs/metadata, all default-uniform subsets and one-lowering parity; Vite unit/dev/build tests prove the default import is an artifact and edits invalidate both targets; public and editor-facing TS tests agree. A production static fixture contains generated GLSL **and** WGSL but excludes parser/compiler code (inspect emitted chunks/module graph, not just an easily minified-away string). The browser compiler produces byte-for-byte equivalent artifact fields for the same source. Stop if artifact shape or compiler splitting makes the static bundle pull in the parser.

## Phase 2 — isolated owned renderers

1. Add separate workspace runtime entry points for WebGL 2 and WebGPU, with no value imports of `@shdr/core` and no cross-import between backends. Extract the working fullscreen-triangle, compilation, binding and lifecycle behavior from the REPL instead of maintaining copies. Each constructor exclusively acquires its own dedicated canvas/context (and WebGPU device), installs the selected target from the **same artifact**, validates a pipeline/program and draws once before reporting success. No automatic backend fallback, existing-device injection or context reuse.
2. Replace WGSL declaration scanning with trusted, compiler-produced binding metadata; validate malformed or mismatched artifacts instead of silently omitting required bindings. Keep fixed WGSL group 0 binding slots when only mouse or time is present. Match the documented opaque presentation mode on both canvases; test a fragment returning alpha below 1 to show it does **not** make the page transparent, without stripping alpha from shader code.
3. Implement automatic sizing/DPR, pointer normalization into physical pixels and elapsed time on both targets; use the Gate 0 coordination hook so the REPL can share one logical mouse and compile epoch across its two canvases. `{ animate: true }` owns one cancellable RAF loop; `{ animate: false }` schedules none and exposes `draw()`. Creation and successful installs render once. A failed install retains the last program/pipeline and epoch if the surface remains valid; destroy candidate/retired resources. Serialize WebGPU validation scopes; generation-check module/pipeline/draw awaits so stale work never commits or overwrites later status.
4. Report unsupported adapter/device, compile/link/pipeline, draw and async loss errors through the frozen channels; do not leave WebGL RAF exceptions unhandled. WebGPU device loss and WebGL context loss stop further draws, invalidate pending installs and require host recreation; disposal cancels RAF/listeners, invalidates in-flight work and releases owned resources. Verify StrictMode-style mount/unmount before async device creation completes, and double-dispose. Resize/loss may invalidate a previously displayed frame; do not promise preservation there.

**Gate 2 acceptance:** independent browser tests import each entry and verify real first-frame pixels; static and manual frames; resolution/DPR, mouse origin and time reset/advance; missing WebGPU API/adapter; no/some/all bindings; malformed artifact rejection; failed replacement; rapid installs; terminal loss; disposal and no lingering RAF/GPU work. Test generated shader warning/error messages without turning them into Shdr diagnostics. Inspect production imports/bundles: WebGL-only contains no WebGPU renderer, WebGPU-only contains no WebGL renderer, and neither contains the compiler/parser. Record minified/gzip sizes rather than promising a fixed threshold without a baseline.

## Phase 3 — adopt the API in both hosts

1. Replace the duplicated direct WebGL setup in [`apps/vite-basic`](../../apps/vite-basic/src/main.ts) with its artifact and public renderer. Prove the **static Vite-built WebGPU path** too (a second canvas or a focused browser fixture), while preserving WebGL on unavailable devices. Update `verify-build.mjs`, `verify-dev.mjs`, pixel tests and docs; check the fixture's production bundle actually excludes parser/compiler modules and unused renderer code where it imports only one backend.
2. Replace the REPL-local renderers with the two workspace runtime imports and compile dynamic source through the opt-in compiler operation. Keep one semantic pass, original-source diagnostics, generated output tabs, last-good-frame behavior, rapid-edit cancellation, WebGL-only fallback and honest target-specific statuses. Wire the agreed coordination hook so moving over **either** preview updates both mouse uniforms and each successful compile starts both clocks from a shared epoch; avoid recreating the renderer on every edit. Remove the old renderer files only after parity tests prove the new code is authoritative.
3. Update root, Vite fixture, REPL and package API documentation with minimal static and browser-editor examples, opaque alpha, canvas ownership, automatic uniforms, explicit backend choice, manual drawing, replacement and terminal-loss handling. Keep transparent compositing, custom uniforms, textures, host-owned resources, auto fallback, error source attribution and npm publishing in [separate follow-ups](../notes.md).

**Final gate:** Vite dev/build and browser tests, independent runtime pixel/lifecycle tests, and REPL dual-preview/parity/fallback regression pass in pinned Chromium/SwiftShader; real output is inspected on both backends, not merely WGSL module validation. Run `pnpm build`, `pnpm check`, `pnpm test`, `pnpm ci:check`, focused fixture/runtime/REPL tests, Prettier, local-link verification and `git diff --check`. Stop for review before publication or adding resources, transparent output or another target. No work in this plan changes the accepted shader language, publishes a package, or promises bit-exact cross-device pixels.
